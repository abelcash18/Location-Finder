What this project handles

  • 1Permission request: the browser asks the user before sharing location data.
  • 2Exact location: your street address and location name are retrieved using reverse geocoding.
  • 3Coordinates: latitude, longitude, accuracy, timestamp, and a map search link are displayed.
  • 4Errors: the app shows specific messages for permission denied, unavailable location, timeout, unsupported geolocation, and insecure browser context.

For local testing, run this file on localhost, for example: python -m http.server 8000
